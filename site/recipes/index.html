Recipes

Build your setup. Paste. Done.

Pick your apps, name your accounts and choose their colours. You get the exact commands to paste into Terminal.

It all happens on this page, and nothing is sent anywhere. Your recipe is kept in the page link, so you can come back to it or share it.

An example recipe

The recipe builder needs JavaScript. Here is a ready recipe instead: a work and a personal Claude account, plus an icon that opens the account you use today.

Terminal: Work + Personal Claude
# 1. Install aidentity. Run this line on its own first.
# When it asks to set up your first account, type n and press Return.
# If it says aidentity is "not on your PATH", do the 2 steps it shows, then go on.
$curl -fsSL https://raw.githubusercontent.com/PiniShv/aidentity/main/install.sh | bash
# 2. Add your accounts.
$aidentity add Claude --profile Work --color blue
$aidentity add Claude --profile Personal --color green
# 3. Keep your original account one click away.
$aidentity add Claude --main
# 4. Open your first new account and sign in.
$aidentity open "Claude Work"
# 5. Show your new icons, then drag them to your Dock.
$open ~/Applications

For other apps, colours and badges, see aidentity add in the guide.

    Pick your apps

    Choose each app you want more than one account in. Pick only apps you already have in Applications: a line for an app that is not installed will fail.

    Browsers too

    These are detected, but not tested. Their own built-in profiles usually do the job better, so try those first.

    Is your app missing?

    These cannot work, so they are not on the list:

    • ChatGPT Classic and other apps written in Swift or AppKit. They have no Chromium inside, so there is no separate-profile option. The newer ChatGPT app is fine.
    • A few Electron apps ignore the separate folder, so every profile would share one account. If you find one, tell us in an issue.

    Another app built on Chromium or Electron may still work. Run aidentity apps to see yours, then use aidentity add by hand.

        5

        Your commands

        Open Terminal (press Cmd + Space, type Terminal, press Return). Paste with Cmd + V, then press Return. Run the install line first, on its own, then paste the rest. Each icon you add prints a line like ✓ Created Claude Work.

        How to install

        curl works on every Mac. If you use Homebrew already, pick it: Terminal then finds aidentity straight away.

        Terminal: your recipe Ready to paste

        Copy all takes only the lines that make your icons. It leaves out the install line, the comments and the lines that open things, so run those yourself when you are ready.

        The link holds your account names, so share it only with people who may see them.

        • “command not found: aidentity”?Terminal does not know where aidentity is yet. Run the install line again and do the 2 steps it shows under “not on your PATH”. Or pick Homebrew above.
        • Safe to run againRunning add again for an icon that exists rebuilds the icon. Its data and sign-in stay as they are.
        • Sign in onceEach new icon opens signed out. Sign in with that account, once. If the app is open, quit it first: some apps finish the sign-in in the window that started first. Why quit first
        • Prefer menus?From version 1.4.0, aidentity ui opens a menu in Terminal. You choose with the arrow keys instead of typing.
        • More optionsProxies, language and other start-up settings: see per-profile settings in the guide.
